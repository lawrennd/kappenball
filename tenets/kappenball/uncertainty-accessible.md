# Tenet: Uncertainty Accessible

## Tenet

**Description**: Kappenball exists to make uncertainty concepts tangible and understandable. Complex probabilistic and entropy concepts should be demonstrated through simple, visual, interactive simulations that reveal the underlying principles without requiring deep mathematical background. The game should serve as a bridge between intuition and theory, making abstract uncertainty concepts concrete and accessible to students and researchers alike.

**Quote**: *"See uncertainty, don't just calculate it."*

**Examples**:
- The billiards simulation visually demonstrates entropy increase as balls scatter from ordered to disordered states
- The falling ball demo shows probabilistic outcomes in a way that students can observe and reason about intuitively
- Visual feedback (velocities, trajectories) makes probabilistic behavior observable in real-time
- The code structure mirrors the conceptual structure, helping students understand both the physics and the mathematics

**Counter-examples**:
- Requiring users to understand advanced mathematics before running the simulation
- Hiding the uncertainty mechanics behind complex abstractions without visual feedback
- Presenting only final numerical results without showing the dynamic process
- Using technical jargon in the interface without explanation or visual context

**Conflicts**:
- **Scientific Rigor**: Simplifying concepts for accessibility might sacrifice mathematical precision
- Resolution: Provide layered understanding - intuitive visuals for beginners, with mathematical details available for advanced users
- **Code Complexity**: Making concepts accessible might require more elaborate visualization code
- Resolution: Accept that educational value justifies additional implementation complexity
